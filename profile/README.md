# Spatialis S.A.S.

Soluciones en SIG, GeoAI y desarrollo geoespacial para clientes públicos y privados en Colombia.

## Qué hacemos

**SIG y consultoría geoespacial.** Análisis, procesamiento y visualización de información geográfica.

**GeoAI y teledetección.** Análisis de imágenes satelitales con inteligencia artificial.

**Catastro.** Apoyo técnico en información catastral y gestión territorial.

**Desarrollo de software geoespacial.** Geovisores, dashboards y plataformas de análisis geoespacial web.

## Demos

- [Geovisores](https://github.com/spatialis-co/geovisores): ArcGIS, Leaflet, MapLibre y OpenLayers.
- [Aplicaciones](https://github.com/spatialis-co/aplicaciones): SIGApp y dashboard SIG.
